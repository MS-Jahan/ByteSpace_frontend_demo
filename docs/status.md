## Done

- **All design routes built** and compared against the Figma PNGs: landing, login, signup, search, course details/lessons/reviews, creator profile, 404 (`src/pages`, `src/sections`, `src/components`).
- **Assets:** Figma exports (shapes, icons) recorded in `public/assets-manifest.json` (`exports`); derived files (`cutouts/`: portraits without baked shadow; `renders/`: 800 px WebP shapes) under `derived`, regenerated by `scripts/make-cutouts.py` and `scripts/make-renders.py`. Fonts self-hosted.
- **Responsive:** `Stage` scaled compositions, mobile restages below 480 px, no horizontal overflow (the check is honest: the body `overflow-x` mask was removed).
- **Opus code review (docs/code-review.md), P1 findings:** 8 of 9 fixed, one partial:
  - auth state shared between `/login` and `/signup`; overflow test that could not fail; visual gate with per-route baselines that fails hard; 7 MB of eager PNGs; per-course curriculum, reviews and derived ratings; toolbar select focus ring; creator state leak and h1 name.
  - P1-4 (browser zoom): Create & Manage art is decorative and small hero/CTA text has a 16 px floor from 961 px up. The hero/CTA copy is still inside the scaled `Stage`, so zoom does not enlarge the hero heading between 961 and 1440 px.
- **Pixel-fidelity pass (this session):** header centring, Poppins tracking (`-0.0125em`), hero/card weights and avatars, shadow-free portrait cutouts and enlarged wrappers so shadows fade softly, rating-bar fills, Reviews/Lessons tab offset.
